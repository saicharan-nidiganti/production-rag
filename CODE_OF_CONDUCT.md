# Code of Conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Everyone who takes part in its issues, pull requests and discussions is expected
to follow it.

In short: be respectful and constructive, assume good intent, critique ideas
and code rather than people, and keep discussion focused on the project.
Harassment, personal attacks and publishing others' private information are not
acceptable.

## Reporting

Report unacceptable behavior privately to the maintainer,
[@saicharan-nidiganti](https://github.com/saicharan-nidiganti) on GitHub,
using a contact method listed on that profile. Don't report it in a public
issue. Reports are kept confidential.

The maintainer may remove, edit or reject comments, commits, code, issues and
other contributions that don't follow this code of conduct, and may restrict
participation for repeated or serious violations.

Security vulnerabilities follow a separate, private process:
[SECURITY.md](SECURITY.md).
